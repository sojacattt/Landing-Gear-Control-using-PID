04 / Controller briefing

QUICK THEORY
P

Proportional

Output follows the present error. Stronger proportional action can speed up response, but a proportional-only system may retain steady-state error.

PI

Proportional + Integral

Integral action accumulates error over time and can remove persistent steady-state error. Too much integral action can cause overshoot and slower settling.

PD

Proportional + Derivative

Derivative action responds to how quickly the error changes. It can improve damping, but it does not generally eliminate steady-state error by itself.

PID

Proportional + Integral + Derivative

Combines present, accumulated and changing error. Performance depends on the plant and tuning; PID is not automatically best in every test.

u(t) = Kp·e(t) + Ki·∫e(t)dt + Kd·de(t)/dt
e(t) = target − measured output

MODEL & ANALYSIS / 05

What system are we controlling?

The mathematical model, assumed parameters, controller gains and response metrics used in this demonstration.

Plant equation

SECOND-ORDER MODEL

The equation is not taken from a specific aircraft or measured SG90. It is a canonical second-order teaching model used to approximate an actuator-driven position change with inertia-like dynamics and damping. The mathematical form follows standard second-order system theory; the numerical values ωₙ = 2.5 rad/s and ζ = 0.35 are chosen assumptions for a visible demonstration, not fitted aircraft parameters.

θ̈ + 2ζωn θ̇ + ωn2 θ = ωn2u
G(s) = Θ(s)/U(s) = ωn2 / (s2 + 2ζωns + ωn2)

For this run, ωn = 2.5 rad/s and ζ = 0.35. Thus 2ζωₙ = 1.75 and ωₙ² = 6.25. Substitution gives:

θ̈ + 1.75θ̇ + 6.25θ = 6.25u
G(s) = 6.25 / (s2 + 1.75s + 6.25)

It is a second-order plant because the highest derivative is θ̈ and the denominator has degree two.

Controller law

PARALLEL PID FORM
e(t) = r(t) − θ(t)
u(t) = sat [ Kpe(t) + Ki∫e(τ)dτ − Kdθ̇(t) ]

The derivative is applied to the model output (derivative-on-measurement), reducing derivative kick at a setpoint change. The control command is limited to 0–180 equivalent degrees, and conditional integration limits windup. The model is discretised on the Arduino with a 20 ms sample interval using a simple forward-Euler update.

Integral action adds a controller state. Therefore, P and PD have a second-order closed-loop characteristic polynomial in this model, while PI and PID generally produce a third-order closed-loop characteristic polynomial.

These characteristic equations assume the unsaturated linear model and unity feedback. The actual Arduino simulation also includes output saturation and conditional anti-windup, so measured time-domain responses should be read from the live data rather than inferred from these polynomials alone.

Where the plant equation comes from

MODEL DERIVATION

A rotating mechanism with inertia, damping and a position-restoring effect can be approximated by a second-order equation. For a simplified position-following model, write:

J θ̈ + c θ̇ + k θ = k u

J represents effective rotational inertia, c represents damping, k represents the restoring/position-following stiffness, and u is the commanded angular position in the normalised model. Divide through by J:

θ̈ + (c/J) θ̇ + (k/J) θ = (k/J) u

Compare the coefficients with the standard second-order form. Define the natural frequency ωn = √(k/J) and damping ratio ζ = c/(2√(Jk)). Then c/J = 2ζωn and k/J = ωn2:

θ̈ + 2ζωn θ̇ + ωn2 θ = ωn2 u

For this demonstration, ωn = 2.5 rad/s and ζ = 0.35 are chosen as illustrative settings. Therefore 2ζωn = 1.75 and ωn2 = 6.25, giving θ̈ + 1.75θ̇ + 6.25θ = 6.25u. Taking the Laplace transform with zero initial conditions gives G(s) = 6.25/(s² + 1.75s + 6.25).

Scientific honesty: this is a canonical teaching approximation, not coefficients measured from a real aircraft landing gear or the SG90. To claim a physically identified landing-gear model, we would need measured plant data and estimates of inertia, damping, actuator/linkage dynamics and loads.

Expected steady-state error with these gains

IDEAL UNSATURATED ANALYSIS

The chosen plant has unity DC gain, G(0) = 1. For P-only control, at steady state θ = u = Kp(r − θ). Rearranging gives:

θss = [Kp/(1 + Kp)] r  ;  ess = r/(1 + Kp)

With Kp = 2 and a 90° target, the theoretical P steady-state error is 90/(1+2) = 30°, or 100 × 30/90 = 33.3% of the target. PD has the same ideal steady-state error because the derivative term becomes zero when the output stops changing. Integral action in PI and PID can drive step steady-state error to zero in a stable, unsaturated system. The 12-second reported value may still show a small residual because the run is finite and the implementation has saturation/anti-windup.

P≈ 30°at 90° target, Kp=2
PI→ 0°ideal step, stable
PD≈ 30°at 90° target, Kp=2
PID→ 0°ideal step, stable

These are theoretical expectations for the linear model, not values to copy into the results table. The comparison table and metric cards use the data produced by the actual Arduino simulation run. PI can also achieve near-zero error; PID is not the only controller with integral action.

How to read the response metrics

TIME-DOMAIN PERFORMANCE
Steady-state error
|ess| = |r − θfinal|. This is the absolute difference between the target and the average angle over the final 0.5 seconds of the run.
Steady-state error (%)
Error percentage = 100 × |ess| / |target|. It expresses the final target error as a percentage of the requested target angle. At the default 90° target, a 30° error is 33.3%.
Percent overshoot (%OS)
%OS = 100 × (θpeak − θfinal) / |θfinal − θinitial| for a rising response. It measures the peak above the controller’s attained final value; interpret it alongside steady-state error because P/PD may settle below the setpoint.
Rise time
Time taken to move from 10% to 90% of the measured response excursion from initial to final value. It indicates how quickly the system makes the main part of the move.
Peak time
Time from the start of the test to the first meaningful maximum. If no meaningful peak occurs during the 12-second window, the dashboard reports “No transient peak”.
Settling time
The earliest time after which the response stays inside a band around its final value. The dashboard uses ±2% of the response excursion, with a 0.5° minimum tolerance; a dash means it did not settle within the recorded window.
Oscillation turns
Count of prominent reversals in response direction. The algorithm ignores sub-degree changes and very closely spaced turns, so this is a simple indicator, not a formal frequency estimate.

How this maps to landing gear

Reference, r
Requested gear position: deploy / retract angle.
Output, θ
Estimated model angle of the gear mechanism.
Error, e
Difference between desired and current model angle.
Damping, ζ
Represents resistance to oscillation in the simplified response.
Actuator command, u
Simplified control effort used to drive the model.
Scope: this is a classroom positioning-model demonstration. Real aircraft gear includes actuator dynamics, linkage geometry, friction, structural loads and locking / position-confirmation mechanisms. It is not flight hardware or a validated aircraft model.

What each controller changes

P
Immediate correction proportional to current error; can leave a nonzero final offset.
PI
Integral action accumulates error and can remove steady-state offset, but may increase overshoot or settling time.
PD
Derivative action reacts to output speed and adds damping; by itself it does not remove the P-controller's steady offset.
PID
Combines proportional correction, integral offset correction and derivative damping. It is often a useful balance when gains are tuned well; it is not guaranteed to win for every plant.
